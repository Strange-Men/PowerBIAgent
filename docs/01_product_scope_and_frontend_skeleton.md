# 01 — 产品范围与前端骨架

> **状态：** M0.1 已确认产品范围和前端骨架方向
> **下一轮细化：** 无需在 M0.2 细化前端，前端正式设计延后至后端链路跑通

---

## 一、产品范围

### 1.1 MVP 包含

- 自然语言驱动的 Power BI 数据问答
- 多轮对话追问（上下文继承）
- 基于固定模板的静态 HTML 报表生成
- 极简 GPT 式对话 Web 页面
- 结构化 Trace 记录

### 1.2 MVP 明确不包含

- 用户权限管理系统
- 多租户数据隔离
- 自定义报表模板编辑器
- 报表定时发送/订阅
- 后台管理页面
- 多 Agent 协作
- Docker 容器化部署
- 任意代码执行能力

## 二、前端骨架

### 2.1 技术栈

- React 18+
- Vite 构建
- 轻量状态管理（React Context 或 zustand）
- 简单 CSS 或轻量组件库

### 2.2 页面布局

```
┌─────────────────────────────────────────┐
│  Header: PowerBIAgent                    │
├─────────────────────────────────────────┤
│                                          │
│          对话消息列表区域                   │
│    (初次进入时显示欢迎语和输入框居中)         │
│                                          │
│  ┌─ 用户消息气泡                          │
│  │  本月销售额是多少？                      │
│  └───────────────────────────────────────│
│                                          │
│  ┌─ 系统回答气泡                          │
│  │  本月销售额为 1,234 万元。               │
│  │  ┌─────────────────────┐              │
│  │  │ 区域   │ 销售额(万元) │              │
│  │  │ 华南   │    456       │              │
│  │  │ 华东   │    389       │              │
│  │  └─────────────────────┘              │
│  │  [报表预览] [下载HTML]                  │
│  └───────────────────────────────────────│
│                                          │
├─────────────────────────────────────────┤
│  [+][DeepSeek ▼] [输入框..........] [发送] │
└─────────────────────────────────────────┘
```

### 2.3 关键交互

| 组件 | 交互行为 |
|------|---------|
| "+"按钮 | 弹出菜单，可选择语义模型或报表模板 |
| 模型选择框 | 下拉切换 LLM（MVP 仅 DeepSeek） |
| 输入框 | 支持 Enter 发送，Shift+Enter 换行 |
| 发送按钮 | 提交问题，输入框禁用直到收到回答 |
| 报表卡片 | 点击预览打开新标签页展示 HTML；提供下载按钮 |
| 错误状态 | 显示错误信息 + 重试按钮 |

### 2.4 前端状态

| 状态 | 处理方式 |
|------|---------|
| 加载中 | 显示打字动画或 loading 指示器 |
| 空数据 | 显示"No results"或"暂无数据" |
| 错误 | 显示错误信息和重试按钮 |
| 网络断开 | 显示连接断开提示 |

### 2.5 前端开发策略

1. **M0.1-M3：** 仅确认骨架，不创建 React 项目
2. **M4-M5：** 后端核心链路验证通过后，创建 React 项目，实现完整对话页面
3. **开发阶段：** 使用 Vite dev server，代理到 FastAPI 后端
