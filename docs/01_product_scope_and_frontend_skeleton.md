## 一、产品范围

### 1.1 MVP 包含

- 自然语言驱动的 Power BI 数据问答
- 多轮对话追问（上下文继承）
- 基于固定模板的静态 HTML 报表生成
- 带左侧栏的 GPT 式极简对话 Web 页面
- AI 组合回答（文字、指标、表格、图表、报表附件）
- 结构化 Trace 记录

### 1.2 MVP 明确不包含

- 用户权限管理系统
- 多租户数据隔离
- 自定义报表模板编辑器
- 报表定时发送/订阅
- 后台管理页面
- 多 Agent 协作
- Docker 容器化部署
- 任意代码执行能力
- 3D 图表、花哨渐变、大面积深色背景
- 彩色仪表盘或多层嵌套面板

## 二、前端骨架

### 2.1 技术栈

- React 18+
- Vite 构建
- 轻量状态管理（React Context 或 zustand）
- 简单 CSS 或轻量组件库

### 2.3 左侧栏详细

| 区域 | 内容 | 状态 |
|------|------|------|
| 标识 | PowerBIAgent 文字标识 + 折叠按钮 | M5 |
| 新聊天 | 新对话入口 | M5 |
| 搜索聊天 | 搜索历史对话 | M4 |
| 项目 | 当前 Power BI 分析项目入口 | M5 |
| 最近报表 | 最近生成的报表列表 | M3 |
| 最近对话 | 最近对话列表，当前选中浅灰背景 | M4 |
| 用户信息 | 底部用户信息和更多菜单 | M5 |

> **左侧栏定位：** 新聊天和对话导航，展示项目入口、最近报表和最近会话。不展示 Trace、日志、Memory 内部状态、系统健康状态或开发调试面板。
>
> **M3/M4/M5 边界：** 左侧栏 React UI 整体属于 M5。表格中的 M3/M4 标注表示后端能力就绪时间（报表资源、会话持久化、搜索），不代表左侧栏在该轮次开发。最近报表列表、最近对话列表、搜索界面等左侧栏 UI 组件统一在 M5 实现。

### 2.4 新聊天欢迎态

- 页面中央保持大量留白
- 简单数据分析图标
- 主标题："今天想分析什么数据？"
- 副标题："可以查询数据、生成报表或开始新的分析。"
- 不展示仪表盘、推荐 KPI 卡、系统模块列表或开发说明
- 底部输入器在欢迎态也显示

### 2.5 已有对话态

#### 顶部
- 左侧显示当前对话标题（如"区域销售分析"）+ 轻量下拉箭头
- 右上角保留分享或导出入口图标
- 不设计复杂导航栏，不展示系统状态/模型 Token/Trace

#### 用户消息
- 位于主内容区右侧
- 使用浅灰圆角气泡
- 文本简洁，不使用高饱和背景、大头像卡片或复杂消息工具栏

#### AI 回答
- 位于主内容区中间偏左
- 默认不使用明显气泡背景
- 内容按自然阅读顺序纵向排列
- 最大内容宽度适中，不铺满超宽屏
- 同一条消息可组合：文字 → 指标 → 表格 → 图表 → 报表附件

#### 表格
- 直接嵌入 AI 回答，白色背景，无厚重外框
- 使用浅灰横向分隔线
- 表头清晰，行距舒适，数字列对齐
- 不做复杂筛选器和分页工作台

#### 图表
- 直接嵌入 AI 回答
- 标题简洁，坐标轴清晰，数据标签可见
- 颜色克制，优先单一蓝色
- 不使用 3D 图表、花哨渐变、复杂交互工具栏
- 图表数据必须来自 QueryResult，LLM 不得虚构

#### 报表附件
- 轻量横向卡片展示
- 包含：文件图标、报表标题、文件类型、"查看报表"、"下载 HTML"
- 属于 AI 消息的一部分，不设计独立复杂报表后台
- 查看和下载能力属于 M3 以后

### 2.6 底部输入器

- 位于主内容区底部
- 宽大的圆角胶囊形容器
- 左侧"+"按钮 → 点击弹出轻量菜单
- 中间文本输入区域，占位文字类似"询问你的 Power BI 数据"
- 右侧模型选择菜单
- 最右黑色圆形发送按钮
- 开始对话后固定或稳定停留在页面底部

### 2.7 "+"菜单

点击"+"按钮后在输入器上方弹出轻量菜单，分为两个分组：

#### 数据模型
- 销售数据
- 利润分析
- 客户增长
- 实际内容来自后端允许的 Power BI 语义模型列表
- 正式联调属于 M2/M5

#### 报表模板
- 销售分析报告
- 月度经营简报
- 趋势对比报告
- 实际内容来自已登记模板白名单
- 正式联调属于 M3/M5

规则：
- 数据模型和报表模板不能混成一个无分类列表
- 当前选中项应有清晰状态
- 未实现或无权限选项必须禁用或隐藏
- 前端不得自行生成不存在的模型和模板

### 2.8 模型菜单

- 视觉上可展示 DeepSeek、GPT-5.6、Mock 等选项（保留未来扩展入口）
- **产品真实边界：**
  - **当前 MVP 正式用户模型只有 DeepSeek**，为唯一启用选项
  - **Mock 仅用于开发和测试**，不应作为正式用户模型展示
  - **GPT-5.6 仅为图片中的未来视觉占位**，不代表当前项目已经接入
- 未来没有真实接入前，其他模型应隐藏或明确禁用
- 当前不形成多模型能力承诺

### 2.9 前端状态

| 状态 | 处理方式 |
|------|---------|
| 加载中 | 消息流中显示简洁等待反馈（如三点加载），不创建独立 Loading 面板 |
| 空数据 | AI 消息说明暂无数据，不生成空图表和假指标 |
| 错误 | 作为普通对话反馈显示，给出简洁错误和可重试提示，不展示完整异常堆栈 |
| 禁用 | 未接入模型、未配置数据模型、未登记模板、未实现功能必须明确禁用，不得制造可点击但无效果的按钮 |
| 网络断开 | 显示连接断开提示 |

### 2.10 响应式原则（M5 实现）

- 桌面端优先
- 窄屏或移动端：左侧栏折叠为抽屉、主对话区占满、输入器保持可操作、表格允许横向滚动、图表适配容器、报表卡片操作不溢出

### 2.11 前端开发策略

1. **M0.1—M4：** 仅确认骨架和视觉规范，不创建 React 项目
2. **M5：** 后端核心链路验证通过后，创建 React 项目，实现完整对话页面
3. **开发阶段：** 使用 Vite dev server，代理到 FastAPI 后端
4. **当前目录不创建** package.json、src、node_modules 或任何 React 代码
